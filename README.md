# Portafolio — Ricardo Medina

Landing de portafolio para Ricardo Medina Hernández, desarrollador full-stack (Querétaro).
Construida con React + Vite, desplegada en GitHub Pages.

## Proyectos destacados
- **SGST** — Plataforma de turismo sustentable de Querétaro
- **Dematiq** — E-commerce de automatización con pagos Mercado Pago

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # salida en dist/
```

## Deploy
Push a `main` dispara el workflow `.github/workflows/deploy.yml` → GitHub Pages en `mexicans-code.github.io/portfolio/`.
